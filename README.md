# Ginger PvP HUD

Ginger PvP HUD is a Fabric client mod for Minecraft Java Edition 1.21.11 that replaces the default main menu with a snowy and candy-themed interface and provides an advanced PvP HUD. The mod features a customizable HUD with health, armor, and coordinates display, smooth transitions, and fluid animations, all while maintaining low performance cost and readability.

## Install

1. Download the latest version of Ginger PvP HUD from the [GitHub releases page](https://github.com/EnderDevelopment/GingerPvPHUD/releases).
2. Place the downloaded `GingerPvPHUD.jar` file into the `mods` folder of your Minecraft instance.
3. Launch Minecraft with the Fabric loader installed.

## Use

1. Launch Minecraft and enjoy the new snowy and candy-themed main menu.
2. Play the game as usual. The PvP HUD will automatically appear during gameplay, displaying your health, armor, and coordinates.

# Ginger PvP HUD

Ginger PvP HUD is a Fabric client mod for Minecraft Java Edition 1.21.11 that replaces the default main menu with a snowy and candy-themed interface and provides an advanced PvP HUD. The mod features a custom main menu with a snowy background and candy rain animation, as well as a customizable HUD that displays essential player information such as health, armor, and coordinates.

## Install

1. Download the latest version of Ginger PvP HUD from the [GitHub releases page](https://github.com/EnderDevelopment/GingerPvPHUD/releases).
2. Place the downloaded `GingerPvPHUD.jar` file in the `mods` folder of your Minecraft instance.
3. Launch Minecraft with the Fabric mod loader installed.

## Use

1. Launch Minecraft and enjoy the new snowy and candy-themed main menu.
2. Play the game as usual, and the custom PvP HUD will be displayed at the bottom of the screen.
3. Customize the HUD position and scale by modifying the configuration file located in the `config` folder of your Minecraft instance.
